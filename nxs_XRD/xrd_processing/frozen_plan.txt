The initial peak guess is selected in two stages in sin2psi_processor.py.

First, `_choose_fit_window()` uses `scipy.signal.find_peaks()` on the raw intensity array with a prominence threshold of 5% of the full intensity range. If that finds peaks, it picks the one with the highest intensity; if not, it falls back to `argmax(intensity)`. It then defines a small window around that index, with width `max(5, int(len(tth) * 0.02))`.

Second, inside `fit_frame()`, that window is turned into the actual initial peak region. If no explicit windows are supplied, the code uses `_choose_fit_window()` and takes the local maximum within that region as `peak_idx`. That window is then passed into `fit_peak()`, where the pseudo-Voigt model gets its own parameter guesses: `two_theta` starts at the x-position of the maximum corrected intensity, `max_intensity` starts at the peak height, and `fwhm` is estimated from the width above half maximum, with fallback defaults if that estimate fails.

So, in short: it first finds the strongest detected peak, then uses the local maximum in that window as the starting peak center.

```python
def _select_peak_window(tth, intensity, seed_center=None, track_window=None):
    if seed_center is not None:
        left = np.searchsorted(tth, seed_center - track_window)
        right = np.searchsorted(tth, seed_center + track_window)
        peak_idx = left + np.argmax(intensity[left:right+1])
        return left, right, peak_idx
    return _choose_fit_window(tth, intensity)
```
